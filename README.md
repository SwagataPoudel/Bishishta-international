# Bishishta International 🌿

A responsive front-end website for **Bishishta International**, an NGO focused on child rights and community health checkups in Nepal. Built during my software development internship at Logic Bit Solution as part of a live client project.

---

## 📌 Project Overview

Bishishta International required a professional website to represent their organisation online, communicate their mission, and present their programmes to donors, partners, and the community. The site was designed and built from scratch following the NGO's brand guidelines, including their official logo and colour palette.

---

## 🚀 Features

- Responsive layout across desktop, tablet, and mobile screen sizes
- Homepage with mission statement and programme highlights
- Child rights and health checkup programme sections
- About and contact pages
- Brand-consistent design using official NGO logo and colours
- Sticky navigation with dropdown menus
- Clean, professional aesthetic suitable for an NGO audience

## 🔧 Getting Started

### Prerequisites
- Node.js installed
- Git installed

### Installation

```bash
git clone https://github.com/SwagataPoudel/Bishishta-international.git
cd Bishishta-international
npm install
npm start
```

The app will run at `http://localhost:3000`

## 🎨 Design Decisions
